FAQ

Common questions.

Is the persona based on me, or is it a fully AI character?

Either. We can build a persona from scratch — entirely fictional, with a custom-trained face — or we can build one trained on your own reference images. Most clients choose a custom AI character. Your real identity stays completely separate.

How does the image generation stay consistent?

We train a LoRA model specifically on the persona's reference images using fal.ai. Every image generated uses this model plus an identity-lock prompt — same face geometry, same physical details, every single generation. No drift over time.

Does Fanvue allow AI personas?

Fanvue's terms permit AI-assisted content. We present personas in line with their policies and monitor for any changes. We also recommend diversifying to OnlyFans early as part of the Growth and Autopilot tiers.

What do I actually need to do after setup?

On Starter and Growth, you review content batches in the operator dashboard before they publish — typically 30–60 minutes per week. On Autopilot, that step is optional — the system generates and publishes without any input required.

How long does setup take?

Typically 10–14 days from signed contract to first post live. LoRA training takes 3–5 days. The rest is persona build, platform configuration, and content pipeline setup. We move fast.

Can you manage multiple personas?

Yes. Each persona is a separate retainer. We're building toward a white-label version of the operator platform for agencies that want to run their own roster — get in touch if that's relevant.
