# Cornerstone AI — Start Here

This folder is the portable source-of-truth pack for Cornerstone AI Enterprises.

## Core rule

Cornerstone is not the brain.

The durable brain is the version-controlled context in this folder and the canonical documents in the repository. Cornerstone is one interface. Local Qwen is one execution model. Claude, Gemini, Grok, ChatGPT or another suitable model can execute the same work when Qwen is unavailable.

Do not let any AI silently replace the operating model with its own preferred strategy.

## Load order

1. CONTEXT_RECEIPT_PROTOCOL.md — required acknowledgement gate
2. CAIG_AI_CONTEXT.md
3. OPERATOR_SALES_PROFILE.md — real operator strengths, sales style and customer experience
4. CARA_LILA_AI_CONTEXT.md and the full character sources when Cara/Lila are involved

6. YOUTUBE_AUTOMATION_AI_CONTEXT.md for YouTube work
7. LOCAL_AI_QWEN.md for local-AI work
8. The exact job-specific instructions and evidence supplied by the operator

## Source-of-truth hierarchy

1. Current live repository and current data state
2. Canonical context documents
3. Historical documentation/commits
4. Model inference

When sources conflict, flag the conflict and prefer the higher source.

## Mandatory context receipt

When a full context packet is pasted into a new AI chat, its first response must be a context receipt only. It must list every source ID, mark each READ / PARTIAL / MISSING, give one source anchor per section, identify conflicts and context limits, and wait for the operator to say PROCEED. No task execution before that. If anything is missing or truncated, the model must say NOT READY rather than guess.

## Portable AI rule

Keep the supplied context intact. Complete the requested work. Preserve output schemas. Do not invent evidence. Keep Track A, Track B and New Life separate. Treat Cara and Lila as fictional creator characters. Treat research as evidence, not truth. Treat reference content as mechanisms to study, not material to copy.

When Qwen is unavailable, continue from the same contract with another model. When a task needs a local-only capability that another AI cannot access, produce the exact downstream work product and state honestly that the local step did not run.

## Update rule

GitHub is the canonical brain. Update these portable files first when the operating model materially changes. Then refresh the relevant external AI project, Gem or chat.

The system is intentionally model-neutral so a provider can be changed without losing the business logic, methods, quality gates or accumulated learning.
