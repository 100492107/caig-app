## Non-negotiable (stolen from what is winning)

1. **First 1–2 seconds** must interrupt — problem, true claim, or refusal. Never a greeting.
2. **Locked faces only** — Cara and Lila reference packs. No drift.
3. **Attention claims must be true** — feelings do not override reality.
4. **Batch** — script all 7, produce, then schedule. Do not one-shot daily.
5. **Measure by lane** — then clone winners, pause empty-view formats.

## Weekly mix

- **2 × Attention** (~30%)
- **3 × Useful**
- **1–2 × Lifestyle**
- **0–1 × Soft commerce** only if a verified affiliate / TikTok Shop path is live

## Posting order

### Post 1 — Useful
**Format:** Quick list / save  
**Concept:** 3 small standards that make an ordinary day feel intentional (not aesthetic fluff — actual standards).  
**First 2s:** Name the problem (“Most people’s day is noise by 10am.”)  
**Job:** Save. Practical. No fake expertise.

### Post 2 — Attention
**Format:** Café / walking duo  
**Concept:** True social rule break — e.g. they do not keep friendships alive only because of history; effort and honesty are the real currency.  
**First 2s:** The hard line, not the setup.  
**Job:** WHAT? → disagree / recognise.  
**Gate:** Full Attention Gate. Claim must be defensible in one calm sentence.

### Post 3 — Lifestyle
**Format:** Getting ready / leaving the house  
**Concept:** Cara builds (what the day is for); Lila notices (what is worth keeping). Small natural difference, no manufactured fight.  
**First 2s:** Action or one line of personality, not “good morning.”  
**Job:** Chemistry and familiarity.

### Post 4 — Useful
**Format:** Pack / decide  
**Concept:** What actually earns space in a short trip bag — decision rule, not haul.  
**First 2s:** “If it doesn’t earn the space, it stays.”  
**Job:** Reusable rule + saves. Factual only.

### Post 5 — Attention
**Format:** GRWM  
**Concept:** One social expectation they refuse when getting dressed — comfort/agency over performing for strangers’ eyes. True preference, not rage.  
**First 2s:** The refusal.  
**Gate:** Full Attention Gate.

### Post 6 — Useful
**Format:** Worth it / not worth it  
**Concept:** One everyday category (sleep, training, tools, clothes) — clear decision rule.  
**First 2s:** The split (“Worth paying for vs theatre.”)  
**Job:** Teach a rule people reuse.

### Post 7 — Lifestyle or soft commerce
**Format:** Ordinary moment  
**Concept:** Personality-first. If a real product path is live, one item they keep using appears *after* the moment lands.  
**First 2s:** Never BUY.  
**Rule:** Soft commerce only with verified path; Fanvue never in caption.

## Hook structures (rotate)

1. Confession → true claim  
2. Social rule → calm refusal  
3. Duo split on one fact  
4. “Everyone pretends X. We don’t.”  
5. Status reversal  
6. Money/options without apology  
7. Boundary without TED talk  

## Production standard

Identity continuity · scene logic · believable behaviour · platform-native · anti-slop  
Attention posts only: full Attention Gate  
Optional CapCut pass: light crop / grain to reduce plastic AI look before publish
