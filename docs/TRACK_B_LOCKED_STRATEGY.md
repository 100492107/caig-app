# Track B — Content Engine Operating Strategy
*Canonical · September 2026 · aligns with docs/CORNERSTONE_MASTER_CONTEXT.md*

## Purpose

Track B is the **Content Intelligence & Production Engine** inside Cornerstone AI Enterprises.

Core loop (**locked vocabulary — use only these names in product UI**):

`Discover → Analyse → Build → Multiply → Publish → Monetise → Measure → Repeat`

| Stage | Operator job |
|-------|----------------|
| Discover | Find what is already winning |
| Analyse | Understand why (mechanism, not copy) |
| Build | Stronger original long-form package |
| Multiply | Shorts / derivatives with lineage |
| Publish | Production queue or live status |
| Monetise | One money test, one metric |
| Measure | Audience + economics → Creative DNA |

Legacy aliases (docs only, not UI): Radar→Discover, Source→part of Analyse, Rebuild/Produce→Build, Learn→Measure.

## Track B is not one niche

Niche is selected at job time from evidence. Gaming, history, stories, documentary, business/money, technology, lifestyle, etc. The loop stays fixed.

## Source-first

Prefer a real reference (URL, upload, notes) before large production spend.

## Reference rule

Teacher, not template. Learn mechanism. Build original. No copied scripts, identity, footage, or near-identical packaging.

## Cara / Lila / Duo

Owned applications under Creators. Character bibles apply when selected. They do not define the whole engine.

**Today money path:** Creators → package → post → Fanvue or affiliate in bio.  
**Engine path:** Discover → Analyse → Build → Production Studio → Publish → Measure.

## Client delivery

Optional commercial branch later. Not primary navigation. Owned media proves the factory first.

## Monetise

Ads, affiliate, shop, Fanvue (where appropriate), sponsorship, products — after audience evidence, not before.

## Success

`Find winner → explain → build stronger original → publish → derivatives → measure → monetise → feed DNA back into Discover`

More files generated is not progress.
