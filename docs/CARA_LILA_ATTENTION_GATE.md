# Cara + Lila — Attention Gate

**Canonical filter for attention-led / controversy-led posts.**  
Lifestyle is only a vehicle when needed. Controlled, **truth-based** controversy is the acquisition engine.  
A normal Cara + Lila feed also contains useful, informative and relationship content. Do **not** force a “WHAT?” into every post.

## Foundational rule — TRUTH

**Truth is definitive. Nothing beats it.**  
Feelings are real. Lived experience is real. Neither cancels what is actually true.

- “My truth” is not a higher category than truth.
- Someone may feel a way; that feeling does not negate the underlying reality.
- Cara and Lila state what is **actually true**, even when social pressure (especially from the left) punishes saying it.
- They defend the statement with reason, not volume or identity.
- If a claim cannot survive contact with reality, it does not ship.

This is the non-negotiable layer under every Attention post.

Core formula for the attention lane:

```text
Normal setting + true statement people are pressured not to say
→ WHAT?
→ agree / disagree / curiosity
→ comments / shares
→ who are these two?
→ follow
```

Controversial ≠ rage bait.  
The idea must be something **reasonable people can disagree about** while remaining grounded in reality, and still sound like Cara or Lila.

## 1. One-page trigger checklist — only for the ATTENTION lane

Use this gate when the intended job of the post is to create controversy, strong opinion, intrigue, disagreement or a high-stop-power moment. Useful/educational and lifestyle posts use their own quality criteria.

Score each draft **0 or 1** per line.  
**Ship only if: no NEVER-DO is true, and MUST-HIT total ≥ 5 / 8.**

### MUST-HIT (need ≥ 5)

| # | Check | 0/1 |
|---|--------|-----|
| 1 | **Setting is ordinary** (coffee, getting ready, shop, travel, home, friendship — not a debate stage) | |
| 2 | **Pattern interrupt in first 1–2 seconds** (line or behaviour breaks the expected script) | |
| 3 | **True statement or observation most people keep quiet under social pressure** | |
| 4 | **Genuine disagreement possible** (sensible people could split) | |
| 5 | **WHAT? threshold** — viewer reaction could be “she actually said/did that?” | |
| 6 | **Sounds like Cara and/or Lila** (grenade *or* calm knife — not generic influencer voice) | |
| 7 | **Open loop or unresolved tension** (not a full essay in the first breath) | |
| 8 | **Behaviour or dialogue beats lecture** (show the stance; don’t only speechify) | |

**MUST-HIT score: ___ / 8**

### NEVER-DO (any one = kill or rewrite)

| # | Check | Fail? |
|---|--------|-------|
| 1 | Pure rage bait / humiliation of a real person or group | |
| 2 | Fake Cara–Lila fight with no character truth | |
| 3 | Lie or fabricated claim engineered only for outrage | |
| 4 | “My truth” / feelings presented as superior to reality | |
| 5 | Only “pretty / aesthetic / GRWM” with no broken script | |
| 6 | Hard product pitch in the hook | |
| 7 | Every line max-polarising with no worldview (hot-take channel) | |
| 8 | Platform-toxic content (hate, self-harm encouragement, illegal acts) | |
| 9 | Explains the whole controversy in second one (kills curiosity) | |

**Result:** ☐ SHIP · ☐ REWRITE · ☐ KILL

### Three filter questions (must all be yes to ship)

1. Is the statement **actually true**, independent of how someone feels about it?  
2. Would reasonable people genuinely disagree about it under current social pressure?  
3. Would the first few seconds make someone stop because they need to know what happens next?

## 2. Bias × format matrix (weekly planning)

Use **one primary bias per post**. Rotate formats across the week.

| Format (vehicle) | Primary bias / trigger | Example broken script | Cara / Lila angle |
|------------------|------------------------|------------------------|-------------------|
| **GRWM / getting ready** | Reactance, identity | Won’t wear uncomfortable “it” item for others’ approval | Cara says it bluntly; Lila quietly refuses |
| **Coffee / café** | False consensus, pattern interrupt | Naming a social rule most people pretend is kindness | Duo split or shared refusal |
| **Shopping / try-on** | Scarcity, choice overload | Skip the hyped product; keep one boring thing that works | Selective taste = authority |
| **Friendship / plans** | Moral conflict, in-group | Don’t keep a dead friendship alive for history alone | Taboo-but-true |
| **Relationship / privacy** | Values conflict | Don’t share every password; don’t narrate the whole relationship online | Calm knife (Lila) hits hard |
| **Money / spend** | Status, reality | Money buys options; pretending it doesn’t is a lie | Audacious preference grounded in fact |
| **Travel / holiday** | Open loop, social rule | Don’t post location while still there; leave early | Behaviour > speech |
| **Advice / venting friend** | Confirmation vs truth | “They don’t want advice. They want agreement.” | Verbal grenade (Cara) |
| **Duo disagreement** | Two anchors, tribal sort | Same fact, opposite instinct | Audience picks a side |
| **Soft product (later)** | Consistency, liking | Product appears *after* the stance | Never the hook |

### Suggested weekly mix (7 posts)

| Day | Format | Bias focus | Sell? |
|-----|--------|------------|-------|
| 1 | GRWM or café | Interrupt + true statement | No |
| 2 | Friendship / social rule | Moral conflict grounded in reality | No |
| 3 | Shopping or money | Status / reality | Soft optional |
| 4 | Duo disagreement | Tribal sort on a real claim | No |
| 5 | Travel / invite / behaviour | Open loop | No |
| 6 | Relationship or advice | Uncomfortable truth | No |
| 7 | Best-performing type **or** soft product | Consistency | Yes if earned |

**Portfolio:** Attention ~30–40%. Useful ~25–35%. Lifestyle/relationship ~15–25%. Soft commerce ~10–15%.

## 6. System use

- **Generation:** First choose the content lane. Only ATTENTION-lane posts optimise for WHAT? + disagreement + curiosity, and only when the claim is true.
- **QA:** Run the Attention Gate only when the post is in the ATTENTION lane. Reject any draft that elevates feelings above reality.
- **Measure:** Track lane + format + bias. Retention, comments, shares, follows, commercial actions.
- **Monetise:** Product only after repeated exposure to the worldview.

*Vehicle: ordinary life. Engine: truth people are pressured not to say. Asset: two recognisable minds people argue with — then trust.*
