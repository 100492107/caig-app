# Cara + Lila — Attention Gate

**Canonical pre-publish filter.**  
Lifestyle is the vehicle. Controlled controversy is the engine.  
Every draft must clear this gate before TikTok, Instagram, or any other platform.

Core formula:

```text
Normal setting + opinion/behaviour most people suppress
→ WHAT?
→ Is she right?
→ What are people saying?
→ Who are these two?
→ (later) I trust how they see the world → buy
```

Controversial ≠ rage bait.  
The idea must be something **reasonable people can disagree about** and still sound like Cara or Lila.

---

## 1. One-page trigger checklist (score before publish)

Score each draft **0 or 1** per line.  
**Ship only if: no NEVER-DO is true, and MUST-HIT total ≥ 5 / 8.**

### MUST-HIT (need ≥ 5)

| # | Check | 0/1 |
|---|--------|-----|
| 1 | **Setting is ordinary** (coffee, getting ready, shop, travel, home, friendship — not a debate stage) | |
| 2 | **Pattern interrupt in first 1–2 seconds** (line or behaviour breaks the expected script) | |
| 3 | **Private truth or social rule most people keep quiet** | |
| 4 | **Genuine disagreement possible** (sensible people could split) | |
| 5 | **WHAT? threshold** — viewer reaction could be “she actually said/did that?” | |
| 6 | **Sounds like Cara and/or Lila** (grenade *or* calm knife — not generic influencer voice) | |
| 7 | **Open loop or unresolved tension** (not a full essay in the first breath) | |
| 8 | **Behaviour or dialogue beats lecture** (show the stance; don’t only speechify) | |

**MUST-HIT score: ___ / 8**

### NEVER-DO (any one = kill or rewrite)

| # | Check | Fail? |
|---|--------|-------|
| 1 | Pure rage bait / humiliation of a real person or group | |
| 2 | Fake Cara–Lila fight with no character truth | |
| 3 | Lie engineered only for outrage | |
| 4 | Only “pretty / aesthetic / GRWM” with no broken script | |
| 5 | Hard product pitch in the hook (sell after attachment, not instead of it) | |
| 6 | Every line max-polarising with no worldview (hot-take channel) | |
| 7 | Platform-toxic content (hate, self-harm encouragement, illegal acts) | |
| 8 | Explains the whole controversy in second one (kills curiosity) | |

**Result:** ☐ SHIP · ☐ REWRITE · ☐ KILL

### Optional strength flags (not required)

- Cara grenade + Lila one-beat reaction  
- Behaviour-only controversy (no monologue)  
- Status reversal / selective refusal (scarce taste)  
- Soft sell only after the idea lands (≤ ~20–30% of weekly posts)

### Three filter questions (must all be yes to ship)

1. What would they say or do here that most people would normally keep to themselves?  
2. Would reasonable people genuinely disagree about it?  
3. Would the first few seconds make someone stop because they need to know what happens next?

## 2. Bias × format matrix (weekly planning)

Use **one primary bias per post**. Rotate formats across the week so the account doesn’t become a single trick.

| Format (vehicle) | Primary bias / trigger | Example broken script | Cara / Lila angle |
|------------------|------------------------|------------------------|-------------------|
| **GRWM / getting ready** | Reactance, identity | Won’t wear uncomfortable “it” item for others’ approval | Cara says it bluntly; Lila quietly refuses |
| **Coffee / café** | False consensus, pattern interrupt | “We don’t actually like brunch.” | Duo split or shared refusal |
| **Shopping / try-on** | Scarcity, choice overload | Skip the hyped product; keep one boring thing that works | Selective taste = authority |
| **Friendship / plans** | Moral conflict, in-group | Don’t answer every message; won’t keep a dead friendship alive for history | Taboo-but-relatable |
| **Relationship / privacy** | Values conflict | Don’t share every password; don’t narrate the whole relationship online | Calm knife (Lila) hits hard |
| **Money / spend** | Status, loss aversion | £1k on one weekend > ten forgettable things | Audacious preference |
| **Travel / holiday** | Open loop, social rule | Don’t post location while still there; leave early | Behaviour > speech |
| **Home / furnish** | Authority, halo | Refuse the “everyone has this” aesthetic | Opinion inside ordinary task |
| **Night out / invite** | Attribution, status reversal | Leave early; say no without a long excuse | Judged behaviour = engagement |
| **Advice / venting friend** | Confirmation vs truth | “They don’t want advice. They want agreement.” | Verbal grenade (Cara) |
| **Duo disagreement** | Two anchors, tribal sort | Same fact, opposite instinct | Audience picks a side |
| **Soft product (later)** | Consistency, liking | Product appears *after* the stance, as “what we actually use” | Never the hook |

### Suggested weekly mix (7 posts)

| Day | Format | Bias focus | Sell? |
|-----|--------|------------|-------|
| 1 | GRWM or café | Interrupt + identity | No |
| 2 | Friendship / social rule | Moral conflict | No |
| 3 | Shopping or money | Scarcity / status | Soft optional |
| 4 | Duo disagreement | Tribal sort | No |
| 5 | Travel / invite / behaviour | Open loop or attribution | No |
| 6 | Relationship or advice | Values / uncomfortable truth | No |
| 7 | Best-performing type replay **or** soft product | Consistency + liking | Yes if earned |

**Ratio:** ~70–80% pure stance/behaviour · ~20–30% soft product in the same worldview.

## 3. Voice cheatsheet

| | Cara | Lila |
|--|------|------|
| **Mode** | Verbal grenade | Calm knife |
| **Delivery** | Blunt, almost casual | Quiet, precise, understated |
| **Danger** | Becomes shouty hot-take | Becomes vague or soft |
| **Best with** | One hard line + minimal softener | One hard line + silence |

Together: ordinary scene → one broken rule → short exchange or visible behaviour → cut before the TED talk.

## 5. System use

- **Generation:** Creator Engine should optimise for WHAT? + disagreement + curiosity, not “relatable lifestyle” alone.  
- **QA:** Human or automated gate runs this checklist before publish.  
- **Measure:** Track which format×bias pairs earn comments/shares; feed winners back into the weekly mix.  
- **Monetise:** Product only after repeated exposure to the worldview — not as the opening act.

*Vehicle: lifestyle. Engine: controlled controversy. Asset: two recognisable minds people argue with — then trust.*
